# Changelog

All notable changes to TabCentral. Versions follow [Semantic Versioning](https://semver.org).

## [Unreleased]

## [0.9.1] - 2026-11-15

- The TabCentral page now has the same tab icon as the settings page, which is readable in dark mode too.
- Sorting a window by title or domain keeps tab groups intact and sorts the tabs inside each group. It is also much faster with many tabs.
- The page no longer seems to hang during long actions such as sorting a large window.
- Clicking the close button of a tab that just slid into place works on the first click.
- Closing tabs animates faster.
- Collapsing or expanding a group in the list also collapses or expands it in the tab bar. The "Collapse/Expand Group in Tab Bar" menu items are gone.
- Closing a window asks for confirmation by default ("Closing Window 2 with 12 tabs. Are you sure?"). The threshold can still be changed in the settings.
- The tab menu starts with the last "move to window" or "move to group" you used, to repeat it on other tabs.
- "Move All … Tabs" can also move a site's tabs into an existing group or a new group named after the site.
- Stored tabs have a context menu: open in the background, move to a window, or remove.
- New "Minimize Window" item in the window menu.
