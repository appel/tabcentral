Stored tabs

"Store Tabs as" saves tabs as bookmarks, in this folder under Other Bookmarks. Renaming it keeps everything stored in it; you can also move the folder in Firefox's bookmarks Library and TabCentral will keep finding it.

Shortcuts

Click a shortcut and press the keys you want: Ctrl or Alt together with a letter, number or function key, optionally with Shift. If a shortcut is already used by Firefox or another add-on, the other one may win.

About

TabCentral

"Great, another tAb mAnaGEr," I hear you sigh. Well, yes. Sorry about that. Just like every other tab manager out there, I made it because there wasn't one that I 100% liked. What I did like is the build-in Firefox View > Open Tabs page. Nice and clean. It's just that I wanted a few more features. Not just search, but sorting, moving, stashing, draggin' 'n droppin'. All that good stuff.

And while I am a web dev by trade, I have little experience with building browser extensions. So I asked Clause to build it for me. And Jeebs on a bycycle, if it didn't crank it out in under an hour.

So I figured I'd share it. I have been dog fooding it for a bit now. So far it seems to be working fine, though I have only been able to test it on Windows 11 and Ubuntu 26.04. I'm sure there are many bugs that haven't reared there head yet. So if you find any, please post them to the issue tracker. Be specific and include screenshots if you can. Also, be patient and kind. I don't get paid to do this, I just do this for the love of the game.

TabCentral was made with the assistance of AI.
